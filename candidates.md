# Real-Life Patch Notes: The Comedy Changelog — 要求与候选

## 要求（源自官网 description，2026-11-25 核对）
- 一行，至多 160 字符。
- 形式：给现实生活或人体 bug 写的软件补丁说明 / changelog 条目，语气要是真实 release note 的简洁公文腔。
- 评审：judge 两两对比，最好笑者胜；前五名平分奖池。

## 候选
1. v3.2.0: fixed a bug where the brain replays embarrassing moments from 2009 at full volume whenever the body attempts sleep.（备选：梗略常见）
2. v2.4.1: patched memory leak causing names to be dropped within 0.3 seconds of introduction; handshake retention improved to one name.
3. v4.0.2: resolved issue where the stomach reports critical hunger 40 minutes after the fridge was declared closed for the night.
4. v1.9.7: fixed left foot colliding with table legs in low-light conditions; toe damage reduced, root cause still under investigation.
5. v5.1.0: known issue — knees now emit an audible alert when standing up. Team has reclassified this as a feature.
6. v2.0.3: fixed dreams rendering in the wrong aspect ratio during fever; subtitles remain unavailable in all regions.
7. v1.0.1: deprecated the appendix. No documentation was provided by the original developer, and support ended several generations ago. ✅ 选定（132 字符）
8. v3.5.2: hunger notifications now snooze correctly after snacks; previously re-fired during the snack itself.
9. v7.1.0: eyes now auto-focus on the fridge light at 2 a.m. Engineering insists this is working as intended.

## 选定理由
候选 7："deprecated the appendix" 把人体器官当废弃 API 处理，公文腔（No documentation was provided / support ended）最像真 release note；"several generations ago" 把时间尺度拉到进化层面，转折干净且不是"3 a.m. 想起尴尬事"那种已被用滥的梗。节奏：短句宣判 + 长句补刀。132 字符合规。
